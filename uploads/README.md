# 📥 uploads/ — 一目瞭然的上傳入口

> 把您的素材直接拖進對應的子資料夾即可，不需再翻找子目錄。

| 子資料夾 | 放什麼 | 支援格式 |
|----------|--------|----------|
| `photos/` | 安溥的照片（會貼在 3D 球體表面） | `.jpg` `.jpeg` `.png` `.webp` |
| `audio/`  | 語錄配樂 / 訪談錄音 / 演唱片段 | `.mp3` `.wav` `.m4a` `.ogg` |
| `texts/`  | 歌詞、語錄、隨筆（純文字） | `.txt` `.md` |

## 🚀 三步驟上傳

1. **把檔案拖進對應的子資料夾**（例如 `anpu_01.jpg` → `uploads/photos/`）
2. **打開 `js/config.js`**，在 `photos` 陣列或 `quotes` 陣列新增一行：

```js
// 照片
{ id: 'p_001', src: 'uploads/photos/anpu_01.jpg', title: '關於我愛你' },

// 語錄 + 配樂
{
  id: 'q_009',
  text: '這裡填您想放的文字…',
  audio: 'uploads/audio/recording_01.mp3'
}
```

3. **儲存後重新整理網頁**，新素材就會出現在 3D 球體上。

## 💡 小提示

- 檔名建議用英文或數字（例：`anpu_01.jpg`），避免中文檔名造成路徑問題
- 照片建議 ≤ 2MB，音檔建議 ≤ 5MP3，否則載入會比較慢
- 不需要在網頁上按「上傳」按鈕——直接拖檔案進資料夾就好
